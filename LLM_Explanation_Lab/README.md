# Lab: Can we trust an AI's explanation?

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/alilouati/data-visualization-using-python/blob/main/LLM_Explanation_Lab/LLM_Explanation_Lab.ipynb)

A short, beginner-friendly lab. No setup and no API key needed.

1. Build a small traffic junction with three stages.
2. A pretend AI advisor picks the next green stage and gives a reason.
3. Check if the reason is true, using the data.
4. Add a safety shield: simple rules that stop very bad decisions.
5. Try it with a real chatbot and check its answer.

Open the notebook with the badge above, then click **Runtime → Run all**.

The traffic in this lab is random (made up). It is a teaching toy, not research code.
